# Data

This directory holds the market data used by the backtests and is **not committed to git** (≈1.6 GB).

Expected layout, one folder per instrument-year (June→June contract windows):

```
data/
├── MNQ_2015/ … MNQ_2025/
│   ├── raw_data.csv               # 1-minute OHLCV (Time,Open,High,Low,Close,Volume; ms epoch)
│   ├── translated_tv_export.csv   # feature-engine output (generated by src/pine_translator.py)
│   └── demo_ml_dataset.csv        # labeled setups (generated by src/pipeline.py)
└── ES_2015/ … ES_2025/            # same layout, S&P 500 futures
```

To rebuild from scratch: set the `DATABENTO_API_KEY` environment variable, run
`python src/download_databento.py` for the raw bars, then `src/run_baseline_backtest.py`
regenerates the translated and labeled files as part of its pipeline.
`data/cache/` is created automatically by `src/htf_bias_strategy.py`.
